# hypothesis:a00-7a952fb6-fbf989

## Hypothesis

**Claim**: Node2Vec embeddings (dim=64, walk_length=40, num_walks=10) combined with UMAP projection enable actionable hypothesis recommendation — finding semantically related hypotheses via cosine similarity with ≥0.70 recall vs ground-truth BFS-2 neighbors.

**Why this matters**: The capillary DAG generates 60+ hypotheses but has no intelligent "what should I work on next" mechanism. Embedding k-NN can surface related hypotheses for context extension, reducing agent cold-start on new domains.

**Prior art**: R3 (verdict:a00-324837df-2546ce-r3) found k-NN overlap = 0.495 with dim=32, walk_length=20, num_walks=5. UMAP not tested. Higher walk params + larger dim may push recall above 0.70.

**Prove it**: Run Node2Vec with dim=64, walk_length=40, num_walks=10 on the 157-node graph. For each hypothesis node, compute cosine k-NN (k=5) vs BFS-2 ground truth. Mean recall ≥ 0.70.

**Disproves it**: Recall < 0.50 — embedding neighborhood is not structurally meaningful at these params, UMAP distorts the space, or the graph is too sparse for walk-based embeddings.

## Experiment Design

1. Load all hypothesis nodes from `nodes/hypothesis/*.md` → build node list with titles/tags/domains
2. Build edge list from `next_edges` and `spawns` fields
3. Train Node2Vec (sg=1 skip-gram, dim=64, walk_length=40, num_walks=10, window=5)
4. Apply UMAP (n_components=16, n_neighbors=15, min_dist=0.1)
5. For each hypothesis: compute k=5 nearest neighbors by cosine similarity in UMAP space
6. Ground truth: BFS-2 neighbors from graph
7. Compute recall = |k-NN ∩ BFS-2| / |BFS-2| (macro average over all hypothesis nodes)

## Expected Outcome

- Recall ≥ 0.70: embeddings are actionable for hypothesis recommendation → extend embedding pipeline
- Recall 0.50–0.69: partial signal, tune params or use hybrid (embedding + graph traversal)
- Recall < 0.50: embeddings alone insufficient → focus on graph structure for recommendations
