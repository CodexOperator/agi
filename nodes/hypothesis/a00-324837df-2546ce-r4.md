## Hypothesis

**Claim**: UMAP projection to 2D preserves local neighborhood structure better than PCA, resulting in higher k-NN overlap with BFS graph neighbors.

**Why this matters**: R3 showed that full 32-dim embeddings capture ~50% of BFS neighborhood structure. But for the scatter renderer and semantic zoom visualization, we need 2D projection. UMAP is specifically designed to preserve local structure (unlike PCA which maximizes global variance). If UMAP outperforms PCA on local structure, the scatter renderer should use UMAP.

**Test**:
1. Train gensim skip-gram (same as R2/R3)
2. Project to 2D via PCA (baseline from R2: Spearman=0.37)
3. Project to 2D via UMAP (n_neighbors=15, min_dist=0.1, metric='cosine')
4. Compute Spearman on 94 pairs for both projections
5. Compute k-NN overlap for both 2D projections (full 32-dim as reference)

**Would prove it**: UMAP Spearman > PCA Spearman (0.37) AND UMAP k-NN overlap > PCA k-NN overlap
**Would disprove it**: UMAP Spearman ≤ PCA Spearman (UMAP worse at preserving topology in 2D)
