# hypothesis:a00-0c8b14af-d1c67c

## Hypothesis

**Claim**: A `verdict` node with status `proved` and confidence ≥ 0.8 can reliably trigger an autonomous builder subagent via the pi subagent tool, closing the loop from research → proof → action.

**What would prove it**:
- A `verdict:proved` node exists with confidence ≥ 0.8
- A `task:t-094` exists representing the spawned agent's work item
- The spawned agent can be verified as dispatched (session log or status check)
- No false positives: low-confidence or `disproved` verdicts do NOT spawn agents

**What would disprove it**:
- Verdict-to-agent latency > 5 seconds under normal load
- Subagent tool not available or returns error
- False positives: disproved/inconclusive verdicts spawn agents

**Testability**: Write an experiment that creates a `proved` verdict node with confidence 0.9, runs the spawn check, and verifies `task:t-094` is created.

**Relation to existing domains**: Extends chain-engine (verdict nodes are the trigger) and autoresearch-tree-skill (subagent spawning is an agent operation). No existing domain covers verdict→action automation.
