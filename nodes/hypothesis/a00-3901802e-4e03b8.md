## Hypothesis

**Claim**: True skip-gram Node2Vec using gensim Word2Vec on random-walk sentences, combined with UMAP dimensionality reduction, produces 2D coordinates that preserve graph topology.

**Test**:
1. Generate random walks on the graph (walk_length=40, walks_per_node=10)
2. Treat each walk as a "sentence" of node IDs
3. Train gensim Word2Vec (skip-gram, dim=64, window=5, epochs=10)
4. Project to 2D via UMAP (n_components=2, min_dist=0.0)
5. Compute Spearman correlation between graph shortest-path distance and embedding Euclidean distance for reachable node pairs
6. Baseline: hash-based R1 gave Spearman = -0.18

**Proved if**: Spearman > 0.3 (moderate positive correlation)
**Disproved if**: Spearman ≤ 0.3 (no or negative correlation)

**Why this differs from R1**:
- R1 used deterministic hash → random vector → PCA (random projection destroys topology)
- R2 uses actual skip-gram learning → embeddings encode walk co-occurrence → UMAP preserves local structure
- Skip-gram explicitly learns: nodes that appear in similar contexts should be close in embedding space
- UMAP is optimized for manifold structure; PCA is a linear projection

**What this would mean**: The embedding layer and the graph topology share a common representation. The capillary DAG is not just a metadata structure — it encodes semantic relationships that persist in latent space.

## Previous Result (R1)

- Hash-based Node2Vec + PCA: Spearman = -0.18 (weak negative, DISPROVED)
- Root cause: hash projection doesn't encode similarity; PCA linear projection of random vectors is random
