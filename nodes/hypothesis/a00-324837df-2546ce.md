# hypothesis:a00-324837df-2546ce

## Hypothesis

**Claim**: Replacing `yaml.safe_load()` with `yaml.load(..., Loader=yaml.CSafeLoader)` in `frontmatter.py` reduces `load_directory` time by 3-5x.

**Proof**: Benchmark before/after on the 3184-node graph. Load time drops from ~1900ms to <600ms.

**Disproof**: CSafeLoader provides <2x speedup → the bottleneck is not YAML parsing.

## Motivation

- Current load time: 1891ms for 3184 nodes
- `yaml.safe_load` uses Python-based SafeLoader (slow)
- `yaml.CSafeLoader` is a C-based parser (3-5x faster in benchmarks)
- This is a pure implementation change, no API changes

## Evidence from iter30b

ThreadPoolExecutor DISPROVED: parallel parsing is 0.7x (slower) due to Python GIL.
CSafeLoader is the next best approach.
