## Hypothesis

**Claim**: Embedding-based k-NN (cosine similarity in skip-gram vector space) returns the same neighbors as BFS graph traversal, with ≥50% overlap at k=5.

**Why this matters**: R2 proved that skip-gram embeddings preserve graph topology (Spearman=0.37). But topology preservation in the aggregate (pairwise distances) doesn't guarantee that nearest-neighbor queries produce the same results. If k-NN in embedding space matches BFS, embeddings serve as a fast approximate index for graph queries — enabling "find similar hypotheses" without traversing the graph.

**Test**:
1. Train gensim skip-gram on graph walks (same as R2)
2. For 200 sampled nodes: find k=5 nearest by cosine similarity in embedding space
3. For same nodes: find k=5 nearest by BFS traversal
4. Compute overlap: what fraction of embedding k-NN are also BFS neighbors (and vice versa)
5. Compute Jaccard similarity: |NN_emb ∩ NN_bfs| / |NN_emb ∪ NN_bfs|

**Would prove it**: mean(overlap) ≥ 0.5 (at least half of embedding neighbors are graph neighbors)
**Would disprove it**: mean(overlap) < 0.3 (embedding space captures something fundamentally different from graph structure)
