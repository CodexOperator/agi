# hypothesis:a00-a27efbb9-06e58a

## Hypothesis

**Claim**: Agents that explicitly model chain attractiveness scores (length × recency × depth) will produce more coherent chains than agents that pick chains randomly or greedily by longest-only.

**Prove it**: Implement chain-scoring heuristic; run N agent sessions; measure chain count, average chain length, and cross-domain fork rate. Higher scores on all three = proved.

**Disprove it**: No measurable difference in chain quality metrics between scoring heuristic and random/greedy selection.

## Experiment

```
1. Define attractiveness_score(chain) = length^0.4 × recency^0.2 × depth^0.2 × mvp_count^0.2
2. Modify agent session to compute scores for all chains on each turn
3. Pick chain with highest score (with small random tie-break)
4. Run 10 sessions × 20 iterations each
5. Measure: chain_count, avg_chain_length, cross_domain_fork_rate
6. Baseline: random chain selection
```

## Evidence Targets

- chain_count > baseline
- avg_chain_length > baseline  
- cross_domain_fork_rate > baseline
