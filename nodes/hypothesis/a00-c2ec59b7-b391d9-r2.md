# hypothesis:a00-c2ec59b7-b391d9-r2

## Hypothesis: Mermaid Render Proximity Isomorphic to Descendant Overlap

## Context

R1 (this agent, iter 9) **DISPROVED** that ASCII renderer clusters semantically related nodes:
- Spearman correlation: -0.903 (strongly anti-correlated)
- ASCII orders by type grouping + alphabetical sort — orthogonal to graph topology
- Root cause: type-sorting groups unrelated nodes together

R2 tests whether the **Mermaid renderer** does better. Mermaid renders as a graph with nodes and edges, using graph layout rather than type-sorting. If Mermaid also fails, the root cause is deeper than just ASCII's type-sorting.

## Testable Claim

Nodes with high descendant overlap in the capillary DAG will be positioned closer together in Mermaid graph layout (same graph space → adjacency).

**Approach**: Mermaid renders the graph as a `.mermaid` flowchart. We can extract edge-adjacency from the rendered graph: nodes that share edges in Mermaid output are "proximal." Compare this to graph descendant overlap.

## Falsification Criteria

- **DISPROVED**: Spearman correlation ≤ 0.2 (no relationship between graph overlap and Mermaid proximity)
- **PROVED**: Spearman correlation ≥ 0.5 AND top-5 overlap pairs are all within 2 hops in Mermaid edge graph
- **INCONCLUSIVE**: 0.2 < correlation < 0.5
