Evaluation framework for measuring capillary DAG health and agent effectiveness. Without metrics, there's no feedback loop to know if the graph is improving vs. accumulating noise. This domain covers: chain quality scoring, verdict accuracy measurement, hypothesis-to-outcome conversion rates, agent productivity metrics, and graph coherence signals.

This fills the missing feedback loop that makes the DAG self-improving rather than just self-accumulating.
